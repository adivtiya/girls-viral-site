How to upload photos & 15s videos (mobile)

  1. Open your repo on mobile browser (use Desktop view if upload button not visible)
  2. Open folder media (or create: Add file → Create new file → name: media/.keep)
  3. Click Add file → Upload files
  4. Select photos or short video (mp4/webm/mov) from phone gallery. Keep video ≤15s and under ~12MB for fast playback.
  5. Commit changes. Reload gallery.html to see new item.

Keep content tasteful and non-explicit — this avoids ad/account issues.
